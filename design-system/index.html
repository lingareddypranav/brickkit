01 · Logo

Mark + wordmark

Host Grotesk Semibold at 0 tracking. Cap-height of the B matches the brick body; baseline matches the body bottom; descenders (the p) sit below the body and are not clipped. Open lockups are brick-only. Tiled lockups keep that same brick and type size, then put the brick in Figma’s 400 square (20 radius) with padding around it.

05 · Bricks

Construction, not decoration

1-, 2-, and 4-wide units from Figma: 150×225, 12px radius, 90×50 studs. Recolor with the four primitives. Orange on a brick is energy, not identity.

Do

Use the SVG paths. Scale uniformly. Fill with blue, cream, charcoal, or orange.

Don’t

Don’t round the studs into perfect circles or add LEGO wordmarks. This is a plan of a brick.

Test · Model

Take it apart

Switch between racecar, spaceship, dinosaur, and Benny. Color is the shaded build. Line drops lighting and paints every brick the page cream so only the edges remain. The left of the first slider is the finished build. Sliding right lifts bricks off in reverse build order.

06 · Reveal

Covered, then clear

The paragraph wraps with the row. 1-, 2-, and 4-wide bricks cover each wrapped line — complete pieces only, never cut or cropped. Each line masks its own row. The first row drops, then the next. Bricks in a row start on their own time. The row above covers the studs of the row below.

09 · Use

How the system behaves

Type

Host Grotesk everywhere. −1% on UI and body. 0% only on the wordmark.

Orange

Primary actions, highlights, one brick in a row. Never backgrounds for long reading.

Blue

Brand, mark, focus rings, construction lines. The color of a plan.

Tap

Minimum 48px targets. This is for kids’ hands on a landing page or tablet.
